# Starbucks-Beverage-Nutrition-Analysis-Dashboard


📊 Project Overview

The Starbucks Beverage & Nutrition Analysis Dashboard is an interactive Power BI data analytics project developed to analyze Starbucks beverage offerings based on their nutritional characteristics and beverage categories.

The dashboard transforms raw beverage-level data into meaningful visual insights, allowing users to explore calories, caffeine, sugar, protein, beverage categories, and preparation types through interactive visualizations and KPIs.

---

🎯 Project Objective

The primary objective of this project is to analyze the Starbucks beverage portfolio and understand how nutritional characteristics vary across different beverage categories and preparations.

The dashboard provides an interactive way to:

* Analyze the overall beverage portfolio
* Compare beverage categories
* Analyze calorie content
* Analyze caffeine content
* Analyze sugar content
* Explore protein content
* Compare different beverage preparations
* Identify nutritional patterns across beverages

📈 Key Performance Indicators

The dashboard includes important nutritional and portfolio-level KPIs such as:

 ☕ Total Beverages

Measures the total number of beverage offerings available in the dataset.

 🔥 Average Calories

Calculates the average calorie content across the beverage portfolio.

 ⚡ Average Caffeine

Measures the average caffeine content across beverages.

 🍬 Average Sugar

Analyzes the average sugar content across the beverage portfolio.

 💪 Protein Content

Allows users to explore protein levels across different beverage offerings.
